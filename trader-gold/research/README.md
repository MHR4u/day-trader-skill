# Saved research artifacts

This folder contains reproducible outputs from the `trader-gold` factory. Raw
market CSV files are intentionally kept outside the repository. The commands
below fetched them into `/tmp/gold-research` for the runs recorded here.

## Public inputs

Daily Gold proxy (not verified broker spot XAUUSD):

- URL: https://github.com/hariomvyas/Commodity-Forecasting/blob/main/Data/gold.csv
- Local file used: `/tmp/gold-research/gold_daily_2000_2022.csv`
- Rows: 5,703 bars, 2000-01-04 to 2022-09-02
- SHA-256: `2456f85acddedd11ec78c56c9bb500e9bb72bb5a2d415a1a0f401e0ec504938e`

MT4-exported XAU/USD H1 (starts in 2004, fails the 2000 gate):

- URL: https://github.com/FeziweMelvin/XAUUSD-Gold-Price/blob/main/XAU_1h_data.csv
- Local file used: `/tmp/gold-research/xauusd_h1_2004_2025.csv`
- Rows: 122,028 bars, 2004-06-11 to 2025-06-06
- SHA-256: `3b94158402f3628e7b2c4a9fb1f37bca412a3116d279303b788a149e0782ef7b`

Download commands used:

```bash
mkdir -p /tmp/gold-research
gh api -H 'Accept: application/vnd.github.raw+json' \
  repos/hariomvyas/Commodity-Forecasting/contents/Data/gold.csv \
  > /tmp/gold-research/gold_daily_2000_2022.csv
gh api -H 'Accept: application/vnd.github.raw+json' \
  repos/FeziweMelvin/XAUUSD-Gold-Price/contents/XAU_1h_data.csv \
  > /tmp/gold-research/xauusd_h1_2004_2025.csv
```

## Runs

- `synthetic-smoke/`: deterministic H1 software test, status `SYNTHETIC_ONLY`.
- `daily-2000-proxy/`: optimized rolling walk-forward on the 2000 daily proxy,
  status `RESEARCH_ONLY`.
- `hourly-2004-xauusd/`: baseline rolling walk-forward on H1 XAUUSD,
  status `RESEARCH_ONLY`.
- `hourly-optimized-a/`: training-only parameter search with a smaller grid,
  status `RESEARCH_ONLY`.
- `hourly-long-only-b/`: training-only long-only parameter search,
  status `RESEARCH_ONLY`.
- `ea-review/`: static MQL5 source review only, no compiler found.

Each research run contains `report.json`, `summary.md`, `trades.csv`,
`equity.csv`, `data_provenance.json`, `resolved_config.json` and
`GoldProfessionalEA.research.set`. The set file has `InpEnableNewEntries=false`.

`iterations.json` and `iterations.md` are generated by:

```bash
python3 trader-gold/research/summarize.py
```

The full interpretation is in `../docs/research-log.md`. No run is live
approved. All reports keep `deployment_status: MT5_VALIDATION_REQUIRED`.
