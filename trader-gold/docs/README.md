# trader-gold documentation

This folder explains the research system behind `/trader-gold`. Start with the
skill instructions in `../SKILL.md`, then use these notes:

- `architecture.md`: the six agents, data flow and core design decisions.
- `data-and-validation.md`: CSV formats, the 2000 coverage gate, walk-forward,
  cost stress and result statuses.
- `mt5.md`: EA compilation, all-timeframe behavior, safety controls and the
  required real-tick validation checklist.
- `research-log.md`: reproducible commands and results from synthetic and
  public-data runs, with their limitations.

All documents are research notes. None of them is financial advice, a
compilation certificate, a live-trading approval or a promise of profit.
